# Prompt v4.1 — triagem do Gmail com memória de exemplos

Data: 14/11/2026. Base: v4.0 (`v4.md`). Os prompts de análise SIG e resumo SIE não mudam.

## O que mudou

O WF-08 consulta `GET /api/llm/exemplos?remetente=&assunto=&emissor=` antes de chamar a LLM. A API devolve até 4 documentos
já decididos pelo operador, pontuados por semelhança (mesmo remetente +5, mesmo domínio +3, mesma empresa +3, palavras do
assunto em comum até +2). Cada exemplo traz rótulo (`cobranca_provedor` ou `nao_cobranca`), remetente, assunto, provedor e
local (ou motivo do descarte) e, quando houver, a correção feita pelo operador. Nenhum valor fiscal é enviado.

Seção acrescentada ao prompt de sistema (`n8n/wf08/prompt_classificacao.md`):

```
Exemplos confirmados (quando houver):
- São decisões do operador para documentos PARECIDOS (mesmo remetente, empresa ou assunto). Use-os como a principal referência para tipoDocumento e provedorNome.
- Se um exemplo do mesmo remetente diz "NÃO É COBRANÇA", só classifique como cobrança se o documento atual mostrar claramente uma fatura de internet/telecom.
- Nunca copie valor, vencimento ou número dos exemplos: esses campos vêm só do documento atual.
```

## Segurança

- Os exemplos vão como dado, numa linha cada, com texto cortado (assunto 90, arquivo 60, nomes 80 caracteres).
- A regra do SIGp continua decidindo o status; a LLM só sugere. Se a busca de exemplos falhar, o fluxo segue sem eles.
